¿Cómo se calcula?

Factor de equivalencia de carga (LEF) para pavimento flexible, AASHTO 1993.

log₁₀(LEF) = 4.79 log₁₀(19) − 4.79 log₁₀(L + C) + 4.33 log₁₀(C) + Gt/B − Gt/B₁₈

B = 0.40 + [0.081(L + C)³·²³] / [(SN + 1)⁵·¹⁹ C³·²³]
Gt = log₁₀[(4.2 − pt)/(4.2 − 1.5)]

L = carga del grupo en kip; C = código de configuración (1 simple, 2 tandem, 3 tridem); B₁₈ corresponde al eje patrón simple de 18 kip. Para acumulación: ESAL₍acum₎ = ESAL₍día, carril₎ × 365 × Σ(1 + g)ʸ.

Referencia de ecuación y ejemplos: Flexible Pavement ESAL Equation. La ecuación es del método AASHTO 93; consulta la Guía AASHTO y normativa local para proyectos profesionales.
